# QR Lume

Gerador de QR Code simples, privado e pronto para o GitHub Pages.

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Publicação

1. Envie o projeto para um repositório no GitHub usando a branch `main`.
2. Em **Settings → Pages → Build and deployment**, escolha **GitHub Actions**.
3. A publicação será executada automaticamente a cada novo push.

O QR Code é gerado inteiramente no navegador. Nenhum texto ou link é enviado
para servidores externos.
